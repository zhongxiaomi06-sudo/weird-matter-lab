# Weird Matter Lab

Independent GitHub delivery repository for the Eazo Mini App `weird-matter-lab`. This repository contains exactly one Mini App and its paired reusable Skill.

- App source: [`apps/weird-matter-lab`](./apps/weird-matter-lab/)
- Skill: [`skills/explain-weird-materials`](./skills/explain-weird-materials/)
- Delivery status: [`HANDOFF-STATUS.md`](./HANDOFF-STATUS.md)
- GitHub: https://github.com/zhongxiaomi06-sudo/weird-matter-lab

## Run

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## Verify

```bash
pnpm verify
pnpm test:e2e
```

The repository state remains governed by the app's `RELEASE.md`; a successful build is not Owner approval or `READY_FOR_EAZO`.
